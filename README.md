**Project Overview:**

This project explores the application of Generative Adversarial Networks (GANs) to medical image generation using the MedMNIST dataset. We implemented and compared three GAN variants: Least Squares GAN (LS-GAN), Wasserstein GAN (WGAN), and WGAN with Gradient Penalty (WGAN-GP). Each model was trained for at least 50 epochs, and their performance was evaluated using Inception Score (IS), Fréchet Inception Distance (FID), and visual inspection. TensorBoard was utilized for visualizing the training process and generated images. The repository contains the code for each GAN variant, data loading, training, and evaluation, along with the trained models and generated image outputs.
